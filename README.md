# Ferme aux chats

Jeu de ferme cosy en vue isométrique. Voir `docs/roadmap.md`.

## Lancer le jeu

Il faut [Node.js](https://nodejs.org) (version 20 ou plus).

```
npm install
npm run dev
```

Ouvre l'adresse affichée. Pour tester sur ton téléphone (même wifi), ouvre l'adresse « Network ».

## Mettre en ligne

Chaque push sur `main` publie le jeu sur GitHub Pages (voir `.github/workflows/deploy.yml`).
À activer une seule fois : Settings → Pages → Source : « GitHub Actions ».
